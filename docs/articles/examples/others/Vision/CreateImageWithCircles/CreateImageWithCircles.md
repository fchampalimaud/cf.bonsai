# Create Image with Circles

This example demonstrates how to compose an image with circles in it.

## Workflow

:::workflow
![Example](~/articles/examples/others/Vision/CreateImageWithCircles/CreateImageWithCircles.bonsai)
:::

## Details

1. Creates a new image with three circles everytime 'A' is pressed
    1. Creates a black canvas sized 100x100
    2. Adds a white circle centered at (50,50) with a 40-pixel radius to the
       canvas
    3. Adds a white circle centered at (50,50) with a 20-pixel radius to the
       canvas
    4. Adds a white circle centered at (50,50) with a 10-pixel radius to the
       canvas
    5. Generates the three-circle image
